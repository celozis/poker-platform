# Функционал системы и ручная проверка

Состояние на 29.09.2026, после шага 12 (тикет #13, отчёты владельца). Документ собран по всем двенадцати отчётам из этой папки, по документу «Видение платформы и вопросы» и по коду экранов. Названия кнопок и надписей здесь приведены дословно, как они выглядят на экране.

Как пользоваться документом:

- **Разделы 1–3** — справка: где что открывается и кто что может.
- **Раздел 4** — все экраны по порядку: каждая кнопка, когда она видна и что делает. У каждого пункта есть квадратик `[ ]` и ожидаемый результат после стрелки →. Если результат другой, это ошибка: запишите номер пункта (например, «Т7») и что вы увидели.
- **Раздел 5** — сквозной сценарий: в каком порядке пройти всё за один раз, примерно за 1–1,5 часа.
- **Разделы 6–7** — чего система пока не умеет и на чём легко споткнуться при проверке.

## 1. Подготовка к проверке

### 1.1 Запуск

Всё работает локально в Docker (Docker Desktop должен быть запущен).

```bash
docker compose up -d --build                     # поднять всё: база, backend, сайт, Telegram-бот
docker compose exec backend python -m app.seed   # тестовые клубы, администраторы и владельцы (можно запускать повторно)
docker compose exec backend python -m app.demo   # демо-данные: клубы, персонал, игроки, турниры всех видов (раздел 1.5)
docker compose ps                                # все четыре сервиса: db, backend, frontend, bot — Up
```

### 1.2 Как получить код входа

SMS в прототипе не отправляется: код пишется в лог backend. Он действует 5 минут. Новый код на тот же номер выдаётся не чаще раза в минуту: если запросили раньше, используйте прежний.

| Куда входим | Git Bash | PowerShell |
|---|---|---|
| Админ-панель (администратор и владелец) | `docker compose logs backend \| grep "Код входа для"` | `docker compose logs backend \| Select-String "Код входа для"` |
| Кабинет игрока | `docker compose logs backend \| grep "кабинет игрока"` | `docker compose logs backend \| Select-String "кабинет игрока"` |

Берите **последнюю** строку с нужным телефоном. Код админки не открывает кабинет, и наоборот.

### 1.4 Несколько ролей одновременно

- **Администратор и владелец** пользуются одной cookie. В одном окне браузера одновременно войти можно только под кем-то одним. Для второго используйте окно инкогнито или другой браузер.
- **Кабинет игрока** хранит вход отдельно. Его можно держать открытым в том же браузере, что и админку.
- **Табло** входа не требует. Его удобно держать во втором окне рядом с админкой.

### 1.5 Демо-данные: что лежит в рабочей базе

Команда `docker compose exec backend python -m app.demo` удаляет все турниры и всех игроков без привязанного Telegram и заполняет базу заново. Время считается от момента запуска: турниры, которые «идут сейчас», начаты за 30–130 минут до запуска и доиграны до этой минуты, их таймеры идут дальше. **Запускайте её заново перед каждым сеансом проверки или записью видео**, иначе «идущие» турниры за несколько часов уйдут на поздние уровни.

Всё создано через тот же API, которым пользуется админ-панель, поэтому рассадка, места, очки, касса и таймеры посчитаны самой системой. Рассадка случайная, поэтому кто за каким столом и кто кем выбит, при каждой перезаливке своё. Деньги принимали разные сотрудники: чаще первый администратор, иногда второй и владелец. ### 1.6 Три правила времени, без которых проверка «не работает»

1. **Приход можно отметить только с 12 часов до начала турнира до 12 часов после него.** Поэтому для проверки создавайте турнир, который начнётся через 1–2 часа.
2. **Для старта турнира нужны хотя бы двое пришедших.**
3. Время везде — время лиги, **UTC+7 (Новосибирск)**. Если часовой пояс компьютера другой, время в админке будет сдвинуто относительно бота.

## 4. Все экраны, кнопки и чек-лист

### 4.1 Вход в админ-панель — http://localhost:5173/admin

На экране: знак «Сибирская лига покера», заголовок «Вход для администратора клуба», поле «Номер телефона», кнопка **«Получить код»**. После неё появляются поле «Код из SMS», кнопки **«Войти»** и **«Изменить номер»**. Внизу страницы строка статуса: «API работает · База данных доступна».

- [ ] **В1.** Ввести `8 999 000-00-01`, нажать «Получить код». → Появилось поле «Код из SMS», в логе строка «Код входа для +79990000001: …».
- [ ] **В2.** Ввести неверный код. → «Неверный или просроченный код», панель не открылась.
- [ ] **В3.** «Изменить номер». → Возврат к полю телефона.
- [ ] **В4.** Верный код, «Войти». → Панель: шапка в синем цвете «Оби», логотип, «Покер-клуб «Обь»», «Анна Соколова», кнопка **«Выйти»**. Разделы **Турниры · Игроки · Рейтинг**, раздела «Отчёты» нет.
- [ ] **В5.** Обновить страницу (F5). → Остаётся в панели, вход держится 7 дней.
- [ ] **В6.** «Выйти». → Снова экран входа.
- [ ] **В7.** Войти владельцем «Оби» (`+7 999 000-00-11`). → Та же панель, в шапке «Олег Владимиров», разделов четыре: **Турниры · Игроки · Рейтинг · Отчёты**.
- [ ] **В8.** Войти за «Енисей» (`+7 999 000-00-02`). → Бордовая шапка, логотип «Енисея». Турниров и игроков «Оби» не видно.
- [ ] **В9.** Ввести незнакомый номер, например `+7 900 111-11-11`. → Форма ведёт себя так же (поле кода появляется), но кода в логе нет. Так задумано: система не выдаёт, чей номер есть в базе.

### 4.2 Раздел «Турниры» (администратор и владелец)

**Список.** Кнопка **«Создать турнир»**. Секции:

- **«Идут сейчас»** — только если что-то идёт или стоит на паузе;
- **«Предстоящие»** — в том числе не начатые вовремя; отменённые остаются здесь до своего времени начала;
- **«Прошедшие»** — завершённые и отменённые после времени начала, последние сверху.

В строке: название, дата и время, бай-ин, стек и метка статуса («Идёт», «Пауза», «Завершён», «Отменён»; у запланированного метки нет). Отменённый турнир зачёркнут.

| Кнопка в строке | Когда видна |
|---|---|
| **Регистрации** | всегда |
| **Проведение** | у всех, кроме отменённых |
| **Касса** | всегда |
| **Результаты** | у завершённых |
| **Изменить**, **Отменить турнир** | только у не начатого и не отменённого |

**Форма «Новый турнир» / «Изменить турнир «…»».**

- Поля: **Название**, **Начало** (дата и время), **Бай-ин, ₽**, **Стартовый стек**, **Мест за столом** (по умолчанию 9, от 2 до 10).
- Блок «Структура блайндов»:
  - список **«Шаблон структуры»**: «Стандартная лиги (уровни по 20 минут)», перерывы по 10, или «Турбо (уровни по 10 минут)», перерывы по 5;
  - таблица «Уровень · Малый блайнд · Большой блайнд · Анте · Минут»;
  - у уровня кнопки **«+ перерыв»** и **«Удалить»**, у перерыва **«Удалить»**;
  - под таблицей **«Добавить уровень»**: копия последнего уровня с удвоенными блайндами.
- Блок «Правила»: **Re-entry до уровня**, **Add-on на уровне**, **Фишек за add-on**, **Стоимость add-on, ₽**, **Поздняя регистрация до уровня**. Пустое поле значит «не разрешено». Уровни считаются без перерывов.
- Кнопки: **«Сохранить турнир»**, **«Назад к списку»**.

- [ ] **Т1.** «Создать турнир». → Форма, структура уже заполнена из «Стандартная лиги».
- [ ] **Т2.** Выбрать шаблон «Турбо». → Структура заменилась: уровни по 10 минут.
- [ ] **Т3.** Поменять большой блайнд уровня, удалить уровень, «Добавить уровень», «+ перерыв» после уровня 2. → Таблица меняется, номера уровней пересчитываются без перерывов.
- [ ] **Т4.** Сохранить с началом в прошлом и «Add-on на уровне» = 40. → Красный блок «Турнир не сохранён:» со всеми причинами сразу («Время начала уже прошло», «Add-on: уровня 40 нет в структуре…»). Введённое не пропало.
- [ ] **Т5.** Add-on на уровне 2 без «Фишек за add-on» и без «Стоимости add-on». → Причины «Add-on: укажите, сколько фишек он даёт» и про стоимость.
- [ ] **Т6.** Заполнить правильно: начало через 1–2 часа, бай-ин 1500, стек 20000, мест за столом 4, re-entry до 2, add-on на 2, фишек 30000, стоимость 1000, поздняя регистрация до 3. «Сохранить турнир». → Турнир в «Предстоящих», дата, «бай-ин 1 500 ₽ · стек 20 000».
- [ ] **Т7.** «Изменить» у этого турнира. → Форма заполнена прежними значениями. Поменять бай-ин, сохранить. → В списке новый бай-ин.
- [ ] **Т8.** Создать второй турнир и «Отменить турнир» → «Отмена» в окне подтверждения. → Ничего не поменялось.
- [ ] **Т9.** «Отменить турнир» → «ОК». → Турнир зачёркнут, метка «Отменён». Кнопок «Изменить», «Отменить турнир», «Проведение» у него нет.
- [ ] **Т10.** Турнир, который уже начали (после раздела 4.5), в секции «Идут сейчас». Кнопок «Изменить» и «Отменить турнир» у него нет.

### 4.3 Раздел «Игроки» (администратор и владелец)

- Блок **«Новый игрок»**: поля **Имя**, **Телефон** (в любом виде: `8 913…`, `+7 (913)…`), галочка «Игрок согласен на обработку персональных данных (152-ФЗ)…», кнопка **«Добавить игрока»**.
- Блок **«Игроки клуба»**: поиск «Поиск по имени или телефону», список «имя — телефон».

- [ ] **И1.** Имя, телефон, без галочки → «Добавить игрока». → «Игрок не добавлен: Без согласия на обработку персональных данных игрока завести нельзя». Введённое не пропало.
- [ ] **И2.** С галочкой. → Зелёное «Игрок … добавлен», игрок в списке, форма очистилась.
- [ ] **И3.** Телефон из 10 цифр. → «Телефон: нужен российский номер из 11 цифр…».
- [ ] **И4.** Тот же телефон ещё раз, с другим именем. → «Игрок … уже есть в вашем клубе», дубля нет.

### 4.5 Страница «Проведение» турнира

Открывается кнопкой **«Проведение»**.

**Когда турнир идёт.**

- **Таймер**:
  - название уровня или «Перерыв», блайнды и анте, строка «Дальше: …»;

  - Кнопка **«Add-on»** — пока открыто окно add-on и игрок не брал его в этом входе.
  - Кнопка **«Отметить выбывание»** — с подтверждением «Игрок … выбыл?».
- **«Поздняя регистрация»** — пока открыто окно:

  - поиск игрока клуба с кнопкой **«Посадить»**;
  - «Новый игрок» → **«Добавить и посадить»**.
- **«Выбывшие»**: «N место», имя, у каждого кнопки **«Re-entry»** (пока открыто окно) и **«Отменить выбывание»**.

**После завершения.** «Турнир завершён», кнопка **«Результаты и исправление мест»**, блок **«Итоги»** с местами и очками, кнопок у игроков нет.

### 4.11 Кабинет игрока — http://localhost:5173

Вёрстка рассчитана на телефон. Проверяйте в режиме телефона: Chrome → F12 → значок устройства → например, iPhone 12.

- Шапка: знак лиги, кнопка **«Выйти»**.
- **«Профиль»**: Имя, Телефон, Клуб (или «Клубы»), Telegram «привязан» или «не привязан».
- **«Рейтинг»**: сезон и по каждому клубу игрока «N-е место · X очков · Y турниров» (или «пока нет в рейтинге»).

## 6. Чего система пока НЕ умеет

Для сравнения с документом «Видение платформы и вопросы»: это не ошибки, а не сделанное.

**Игрок**
- Нет мобильного приложения (App Store / Google Play) и мини-приложения Telegram: только бот и кабинет в браузере.
- Нет записи и отмены записи из кабинета (только в боте), нет правки профиля.
- Нет листа ожидания, числа свободных мест и лимита участников турнира.
- Нет расписания по всей сети сразу: только свой клуб (в боте) или свои клубы (в кабинете).
- Нет статусов игрока (гость → постоянный → VIP), скидок и связи с ЮДС.
- Нет реферальных ссылок-приглашений.
- Нет «моего стола и места» во время турнира в боте или кабинете.
- Нет меню бара.
- Нет входа через VK или Telegram на сайте, только телефон и код.
- Нет рейтинга города и России/СНГ, есть только рейтинг клуба. Нет очков за нокауты (баунти).
- Нет рейтинга прошлых сезонов в кабинете (в админке есть).
- Нет повторного сообщения, если место исправили после отправки результата.

**Персонал**
- Нет ролей дилера, флор-менеджера, бара, SMM и владельца сети; нет сводной панели по всем клубам.
- Нет журнала действий (кто что отметил или исправил).
- Нет карточки игрока в админке (первый визит, все турниры игрока), списков «ушедших», рассылок через бота.
- Нет настройки брендинга клуба через интерфейс (логотип и цвета задаются сидом).
- Нет своих шаблонов структуры: два шаблона лиги зашиты в код. Нет вставки уровня в середину структуры (только в конец).
- Нет удаления игрока и отзыва согласия (152-ФЗ).
- Нет наглядной схемы стола «по кругу» и позиции дилера: рассадка показана списком.
- Нет фонового изображения на табло.
- Нет выгрузки результатов турнира в CSV или PDF (CSV есть у кассы и у отчётов).

**Деньги и интеграции**
- Нет онлайн-оплаты: только наличные и карта на месте.
- Нет аренды инвентаря, бара и ручных кассовых операций: деньги появляются только из действий в игре.
- Нет интеграций с iiko, 1С, ЮДС и эквайрингом.

**Техническое**
- SMS не отправляются: коды входа пишутся в лог.
- Нет часовых поясов клубов: всё по UTC+7.
- Не сделан деплой на сервер (следующий тикет #14): всё работает только локально.

## 7. На чём легко споткнуться при проверке

| Что видите | Почему | Что делать |
|---|---|---|
| Нет кнопки «Отметить приход» | До начала турнира больше 12 часов, турнир уже начат или отменён | Создать турнир, который начнётся через 1–2 часа |
| «Для старта нужны хотя бы два пришедших игрока» | Приход отмечен меньше чем у двоих | Отметить приход |
| Кода нет в логе | Номера нет в базе, или код уже запрашивали меньше минуты назад | Проверить номер; взять прежний код или подождать минуту |
| «Неверный или просроченный код» при верном коде | Взят код не того входа (админка или кабинет), код старше 5 минут или 5 неверных попыток | Запросить новый и взять нужную строку лога |
| Вошли владельцем, а в соседней вкладке «пропала» админка администратора | У администратора и владельца одна cookie | Второго держать в окне инкогнито |
| Нет раздела «Отчёты» | Вошли администратором | Войти владельцем (…-11 или …-12) |
| Нет кнопок «Re-entry», «Add-on», блока «Поздняя регистрация» | Окно по уровню закрыто или не задано в правилах турнира | Подсказки под таймером; «Предыдущий уровень» |
| Место выбывшего изменилось | После него был re-entry или поздняя посадка: места считаются по порядку выбывания | Так задумано |
| Бот не отвечает | Сервис `bot` остановлен или нет токена в `.env` | `docker compose ps`, `docker compose logs bot`, `docker compose up -d bot` |
| Запись из бота не появилась в админке сама | Страница была открыта до перезапуска backend | Обновить страницу |
| Результат турнира не пришёл в бот | Telegram игрока не привязан, или турнир завершён больше суток назад | Место и очки видны в `/rating` и в кабинете |
| Время в админке отличается от бота на несколько часов | Часовой пояс компьютера не UTC+7 | Для проверки поставить в Windows пояс Новосибирска |
| «Идущие» турниры ушли на поздние уровни, окна re-entry и поздней регистрации закрыты | Демо-данные залиты давно, таймеры шли всё это время | Перезалить: `docker compose exec backend python -m app.demo` |
| Excel показывает кракозябры в CSV | Файл открыт через «Импорт» с другой кодировкой | Открыть двойным щелчком |
